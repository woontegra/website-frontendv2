# Görseller

Tüm statik görseller bu klasöre konur ve sitede `/images/dosya-adi.png` ile kullanılır.

Önerilen dosyalar (ilk kurulum):

- `logo.png` — header logosu
- `favicon.png` — sekme ikonu
- `hero-dashboard.png` — ana sayfa hero
- `excel-vs-program.png` — Excel karşılaştırma bölümü

Backend upload veya admin `imageUrl` bu projede kullanılmaz.
